# Frontend Dashboard

Standalone React + TypeScript dashboard for Incident Intelligence.

## Run locally

1. Copy env template:
   ```bash
   cp .env.example .env
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the app:
   ```bash
   npm start
   ```

The app runs independently and expects backend APIs at `REACT_APP_API_BASE_URL`.
